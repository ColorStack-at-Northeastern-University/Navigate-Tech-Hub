KEY FINDINGS

[GEM] **Early alignment script (week one):** Ask the manager what “successful internship” means and what would make them **confident recommending you for full-time**—locks a shared bar early. (TechnCV)
[GEM] **Cadence upgrade:** If check-ins are sparse, **increase manager/host touchpoints** (retrospective: sparse → **daily** described as a “game changer” for unblocking and visibility). (Business Insider — Google intern story)
[GEM] **Levels.fyi “Succeed” bundle (attributed):** Treat **mentor** as daily contact surface; **substantial project updates on a high cadence** (their example: daily); **participate in team discussions** and show curiosity about adjacent work; **finish ahead of schedule** and go beyond the minimum so your manager/mentor can advocate. ([Levels.fyi internships guide](https://levels.fyi/internships))
[GEM] **Midpoint checkpoint:** Ask whether you’re **on track for a return offer** and what would strengthen the case in the second half—creates time to course-correct. (TechnCV)
[GEM] **Evidence trail:** Keep a **running log** (wins, blockers, decisions, metrics, praise) and feed it into **final presentation / self-review**; one retrospective used **weekly summaries with screenshots/links** in the reflection. (TechnCV; Business Insider)
[GEM] **Levels.fyi headline stats (careful):** “**56%** of interns receive FT offers” / “some companies **>70%** conversion”—usable only with **clear attribution** and a **methodology caveat** (not sourced on-page). ([Levels.fyi internships guide](https://levels.fyi/internships))
[Finding — supporting] **Team integration is evaluation, not extracurricular:** managers often implicitly poll **“would I want this person as a colleague?”**—lunches, socials, and **cross-functional intros** build affirmative answers. (TechnCV; Medium patterns)
[Finding — supporting] **Feedback loop:** Ask for informal feedback in 1:1s; **show visible behavior change** after feedback (“I applied X on this review…”). (TechnCV)
[Finding — supporting] **Stretch / lasting value:** Competent core delivery is baseline; **durable artifacts** (tooling, docs, automation) can outperform a polished but disposable deliverable. (TechnCV)
[Finding — supporting] **If no offer:** stay professional, ask **why**, request **references/intros**, refresh resume while details are hot. (TechnCV)
[Finding — supporting] **Offer mechanics variance:** committees vs manager-only; offers during internship vs later—**clarify early** so you don’t optimize the wrong signal. (TechnCV)

RECOMMENDED STRUCTURE
Opening hook: **The internship is a long interview**—most students optimize tasks but under-invest in **manager-visible trajectory** until week 8.

Section 1: **Map the decision process** — committee vs manager-led, midpoint review, when offers land; **one conversation** to learn the rules.
Section 2: **Manager + mentor system** — alignment questions, **meeting cadence**, unblocking norms, **“on track?”** checkpoint; tie to Levels.fyi mentor/update guidance **with attribution**.
Section 3: **Team signal** — communication, code quality, improvement curve; social/collab without **performative networking**.
Section 4: **Artifacts of proof** — impact log, demo/presentation prep started week 1, self-review discipline.
Section 5: **Offer chapter** — return FT vs **return internship** edge cases; negotiation **varies** (forum + employer-specific); no shame **no-offer** path.
**Audience mandatory beat (short, concrete):** **visibility equity**—when you’re “the only” on a team, **sponsorship behaviors** (clear asks, documented wins, aligned allies) matter; pair with **community placement context** where first internship—not return—is the bottleneck; still land return-offer levers for those already interning.
The mistake: **treating return offers as a purely technical bar** instead of **advocacy + evidence + relationships**.
Close: **Schedule the alignment 1:1 and start the running log today** (first working week).
